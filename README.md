# 🧠 QuizNova — Interactive Quiz Web Application

QuizNova is a modern, responsive, and interactive quiz web application developed as part of **Task 03** of my Web Development Internship at **SkillCraft Technology**.

The application allows users to choose a quiz category, answer multiple-choice questions, track their score, and view their final performance.

## 📌 Project Overview

QuizNova is designed to make learning more interactive and engaging through category-based quizzes.

Users can:

- Explore different quiz categories
- Select a category
- Answer multiple-choice questions
- Navigate through questions
- Receive instant feedback
- Track correct and incorrect answers
- View their final score
- Check their accuracy
- Restart the quiz
- Choose another category

The interface is designed with a modern dark theme, responsive layout, smooth animations, and interactive UI elements.

---

## ✨ Features

### 🎯 Category-Based Quizzes

Users can choose from multiple categories:

- 🧠 General Knowledge
- 💻 Programming
- 🌐 Web Development
- 🔬 Science
- ⚡ Technology
- 🎬 Entertainment

---

### 📝 Interactive Questions

Each quiz contains multiple-choice questions with several answer options.

Users can select an answer and move through the quiz one question at a time.

---

### 📊 Score Tracking

QuizNova automatically tracks:

- Total questions
- Correct answers
- Incorrect answers
- Accuracy percentage
- Final score

---
